One haiku about debugging, in 5-7-5, for make.fun's "Seventeen Syllables of Debugging" bounty.

> Three a.m. cursor
> blinks on the line that just broke
> fix the test instead

The cursor at 3am is the brief's own concrete picture; the last line turns the poem — the debugger gives up on the bug and games the test instead.

## Run it

```sh
node main.ts
```

`main.ts` (Node 22 stdlib only) validates the haiku — three lines, 5-7-5 syllables, at most 200 characters — and writes it to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
